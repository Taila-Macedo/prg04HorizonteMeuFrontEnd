# 🧭 Horizonte Meu - Seu Atlas de Sonhos Interativo
Conectando viajantes aos destinos mais incríveis do mundo.

O Horizonte Meu é uma plataforma web com características de rede social voltada para viajantes e amantes de turismo. Permite a exploração de pontos turísticos globais, envio de fotos, avaliações de destinos, criação de roteiros personalizados e interação entre a comunidade de viajantes.

## 🚀 Funcionalidades

* 🗺️ Exploração de pontos turísticos por categoria e localização
* 🔍 Busca por nome, país ou cidade
* 📍 Visualização de detalhes (descrição, localização, galeria de fotos)
* ⭐ Sistema de avaliações e comentários
* ❤️ Favoritar pontos turísticos
* 🗺️ Mapa interativo com marcadores
* 📷 Upload de fotos nos pontos turísticos
* 🔔 Notificações de interações
* 👤 Perfil de usuário
* 🔐 Autenticação (login e cadastro)
* 🛠️ Painel administrativo para moderação
